# Gizlilik politikaları (yayın deposu)

Bu depodaki HTML dosyaları **üretilmiştir**; elle düzenlemeyin. Kaynakları
uygulamanın kendi deposundaki `docs/` klasörüdür ve

    bash scripts/gizlilik_yayinla.sh

komutuyla buraya gönderilir (iki sayfa tek commit'te gider).

| Adres | Kapsam | Kaynak |
|---|---|---|
| `/` | uygulamaya özel: Tesbihat | `docs/index.html` |
| `/studyo/` | stüdyo geneli: tüm uygulamalar | `docs/studyo/index.html` |

Bu depo yalnızca herkese açık olmak zorunda olduğu için ayrıdır: GitHub Pages
ücretsiz planda yalnızca public depolarda yayın yapar, uygulamanın kaynak kodu
ise private kalır.
