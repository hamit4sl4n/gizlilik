# Gizlilik politikası (yayın deposu)

Bu depodaki `index.html` **üretilmiştir**; elle düzenlemeyin.
Kaynağı uygulamanın kendi deposundaki `docs/index.html` dosyasıdır ve

    bash scripts/gizlilik_yayinla.sh

komutuyla buraya gönderilir.

Bu depo yalnızca herkese açık olmak zorunda olduğu için ayrıdır: GitHub Pages
ücretsiz planda yalnızca public depolarda yayın yapar, uygulamanın kaynak kodu
ise private kalır.
